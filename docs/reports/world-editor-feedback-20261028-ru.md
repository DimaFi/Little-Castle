# World Editor: вода, брод и цветы после проверки

28.10.2026. Основной проект: **E:/Games_Develop/Little-Castle**.
Кодовая ветка: `codex/world-editor-feedback-code-20261028`, поверх Draft PR81.

## Изменения

- **Цветы доступны явно:** Растительность → Цветы и мелочь → группа Цветы.
  Включите «Рисовать в SceneView» и рисуйте ЛКМ по травяной земле.
  В Play-панели есть кнопка «Цветы · рисовать готовую группу».
- **Цветы видны вне Play.** Временный SceneView renderer использует существующий
  алгоритм размещения, плотность, группировку и seed. Он не запускает runtime
  painter и не меняет исходные assets. Undo/Redo обновляют изображение.
- **Дорожка продолжается в брод:** речное исключение растений больше не стирает
  дорожный канал маски. Правило общее, без проверки имени одной дорожки.
- **Песчаный берег:** существующий SandCoverage подключён к terrain через
  производный UV3. Песок смешивается с грунтом и покрытием пути; сохраняются
  исходные vertex masks, snow/triplanar, освещение и Shadow/Depth passes.
- **Пологий брод:** устранён разрыв между внутренней и внешней ветвями профиля v2
  на границе русла. Высотная формула старого v1 оставлена прежней.
- **Отступ растений:** деревья и мелочь исключены со всей песчаной части склона.
- **Начальная настройка воды:** уменьшены регулярные волны, чрезмерный HDR-блик
  и искажение отражений; изменены оттенки, прозрачность мелководья, масштаб normal
  и его fade distance. Пигменты и каустика реагируют на общие световые глобалы
  до композиции отражений/рефракции/тумана. Течение/flow maps сохранены.

Материал с крупной ячеистой пеной был просмотрен и отвергнут. В итоговом preset
поверхностная пена по площади выключена, береговая пена остаётся включённой.
Это первоначальная доводка, **не воспроизведение качества присланного референса**.
Вода на некоторых ракурсах всё ещё слишком однородная, песчаная полоса широкая,
нужна отдельная визуальная калибровка. Новые скальные/природные ассеты не добавлены.

## Границы публикации

существующего материала воды, тесты и текстовую передачу. Авторская карта,

Проверочный штрих цветов отменён.

| Full PlayMode | **16/16 PASS** |
| Новые проверки | Flower selection/save/Undo, SceneView scatter placement/restore, сохранность дорожного R, обе кромки брода при 0/.5/1, UV3 после Undo/Redo — PASS |

| Последний Player build из открытой Unity | **Succeeded, 0 errors / 0 warnings**; ранее batch build имел 3 obsolete API warnings |
| Сохранность ProjectSettings после build | 3 файла восстановлены побайтно |
| Player с текущей сохранённой картой | **38 PNG**, день/закат/ночь × 11/35/115 м × AO on/off и переход суток; runtime-errors пуст |

Для кадров используется явный диагностический `-weExistingMap`: он не добавляет
проверочную реку поверх вашей карты и не загружает/сохраняет пользовательский
файл Play-сессии. Дельты и Undo/Redo проверены тестами, а не этим capture-режимом.
NOT RUN: большие карты, новый performance benchmark, длительное движение/shimmer,
полный ручной обход каждой кнопки Play-панели и визуальная приёмка уровня референса.

Результаты выше получены в каноническом Main на Windows/Unity.
Кодовые файлы публикации совпадают с проверенными файлами Main; в чистом cloud
clone Unity и лицензированные art fixtures могут быть недоступны — указывать NOT RUN.
Кадры и локальные журналы не входят в эту публикацию.
