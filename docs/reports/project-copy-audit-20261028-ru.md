## Основные механики: результат сравнения

- **Кисти:** независимой реализации из BrushFoundation, отсутствующей в Main,
  не найдено. Preset save/apply и «Вся карта» перемещены в UI partial, не удалены.
  Source MapSurfaceQuery и основные тесты контроллера сохранены.
- **Реки:** команды узлов, перемещения/удаления, песчаного спуска, брода и
  самостоятельных скальных участков есть за «Дополнительно». Исходный экспорт
  Uber shader сохраняет normal/foam/refraction/caustics/reflection/waves/flow.
  Main добавляет общий свет и исправления интеграции, поддерживая старые v1.
- **Свет/GI:** исходники SpatialIndirect и старые сцены сохранены. Отсутствие GI
  в основной World Editor сцене намеренно: не нужно включать экспериментальный
  драйвер, который сам меняет часы/камеру. Gamma-настройки копий не заменяют
  проверенную Linear-конфигурацию Main.
- **Растительность:** рабочий Meadow scatter-каталог содержит те же 39
  прототипов. Сохраняются instancing, ветер, interaction и группы кистей.
  Снег на всех вариантах Oak этим файловым сравнением не подтверждён.
- **Биомы/снег:** audit Probe — старый изолированный PR79-прототип. Его поля и
  полезные проверки перенесены в общую сессию с исправлениями. Отдельный
  BiomeSnowWorld/Editor-input и SnowMaskTextureBridge заменены интегрированными
  MapEditSession/MapEnvironmentPresentation, а не забыты при копировании.
- **Мосты/стены:** 25 бинарных файлов bridge v002 найдены в основном проекте;
  11 FBX и три текстуры wall v005 тоже совпадают. Отсутствующие шесть preview PNG
  стены не являются игровыми зависимостями. Нельзя заменять актуальные модели
  более старыми только ради совпадения всех папок.

## Что действительно не доведено до одного проекта

1. **Библиотека водных пресетов.** В source есть восемь адаптированных UWa
   материалов; в Main подключён рабочий Tropical. Отдельной готовой UI-системы
   выбора source не содержал — материалы назначались в Inspector. Для остальных
   не хватает Normal 1/3 и Noise 1/2/7/8. У Wavy одна актуальная ссылка не
   разрешается даже в исходнике. Восемь .mat нельзя считать готовым переносом
   без выбора зависимостей и проверки.
2. **Редактируемый источник воды.** В Main есть runtime shader, но не перенесены
   оригинальный Shader Graph/subgraphs, переменные Editor-плагина и часть
   intake/export-скриптов. Игра их не вызывает; для редактирования/повторного
   экспорта это остающаяся зависимость от source-копии.
3. **URP study-сцены.** Отдельно остались `GroundBiomes_20261025.unity`,
   `GroundBiomes_PNG_Pass02.unity`, `ValleyArt_Pass03.unity` и `Flowers_Review.unity`.
   Их Assets dependency-замыкания включают соответственно 18/32/55/1
   отсутствующих путей, включая саму сцену. Классы builder/controls есть в Main,
   но Ground/SecondPass/Valley builders защищены именем `Little-Castle_URP_`.
   Соответствующее меню пока не является рабочим Main workflow. Защиту нельзя
   просто удалить: builders перезаписывают свои материалы и стенды.
4. **Полное воспроизведение Quaternius-адаптеров.** 68 исходных Unity FBX не
   лежат в Main, но все 68 побайтово сохранены в исходном MegaKit под
   `E:/Games_Develop/Персонажи/Цветы и части окружения/` и в study-копиях.
   Для готовых baked meshes они не требуются. Повторный
   `QuaterniusNatureIntegration.Integrate` в неполном input tree нельзя считать
   эквивалентным исходному запуску: он пересобирает и перезаписывает каталоги.
   В ходе аудита этот инструмент не запускался.
5. **River study/QA.** MapRiverNavigation, RiverWaterNavigationAudit и
   RiverBankStudy остались в source. Это временный bounded NavMesh bake/path/
   crossing harness, вызываемый только из двух Study сцен, не игровая навигация
   генератора. У Main есть surface-query проверка прохода, но она не заменяет
   полноценную NavMesh-приёмку. Экспериментальные cliff-mesh тесты тоже не перенесены;
   legacy/flow/water-тесты имеют адаптированные проверки Main.

243 отсутствующих в Main файла BrushFoundation и URP имеют **одинаковые пути
и побайтовое содержимое между этими двумя копиями**. Это не 243 потерянных
механики и не две разные уникальные поставки.

## Проверки работоспособности и отложенные проблемы

Последние доступные результаты Main, полученные в предыдущем проходе:
**346/346 EditMode, 16/16 PlayMode**, успешный Player, 0 ошибок сборки и три
obsolete-API предупреждения. XML заново прочитаны. В них есть 44 environment,
30 river EditMode и проверки tool/terrain/tree workflows; они не покрывают
каждый study-builder, альтернативный материал и все визуальные варианты кроны.

**Новые Unity/визуальные прогоны в этом файловом аудите: NOTRUN.**
Текущий пользовательский документ/сессия не прерывались ради повторных тестов.
Наличие всех исходников и прежние зелёные тесты не означают отсутствие ошибок.

Зафиксированы для отдельной последующей работы:

- **Снег на наших крупных дубах:** пользовательская ошибка подтверждена
  предоставленным кадром; точная причина на реальной кроне ещё не установлена.
  Материалы используют LC_Foliage/LC_StylizedLit с default SnowAcceptance=1,
  поэтому просто «шейдер не перенесён» не подтверждается.
- **Снегопад:** SceneView preview создаёт atlas и береговые камни, но не
  MapSnowfallPresentation. Он подключён в runtime painter; ранее Player получил
  кадры со снежинками. Сценарий пользователя нужно проверить отдельно.
  Подключение preview в редакторе пока отсутствует.

Обе задачи **отложены по прямой просьбе пользователя**, исправлений в этом
аудите нет. Подробности: `docs/plans/world-editor-known-issues-20261028-ru.md`.
