# Настройки карты и проверка кнопок — 04.11.2026

В World Editor добавлена кнопка «Настройки систем карты…». Единое Editor-окно
управляет существующими компонентами и профилями, не вводит вторую погодную или
световую систему. Подключение дождя повторяемое: один контроллер, ссылки на
текущие painter/camera/atmosphere. Конфликт открытых сцен явно отклоняется.
Создание профиля не перезаписывает чужой asset. Сохранение ограничено профилями,
не выполняет глобальный SaveAssets для всех dirty ресурсов.

В текущей сцене кнопкой создан и назначен MapWeather.asset; сцена сохранена после
восстановления transient preview. Карта/черновик не применялись к исходной базе.
Основная приватная сцена не публикуется вместе с кодом.

Реальный просмотр выявил наложение игровых панелей: погода перенесена вправо,
а её область исключена из обработки кистей. Автоматическое перемещение Editor
окна при reload создавало пустой HostView и внутренние NullReferenceException
Unity; автоматическое перемещение убрано, пустой host закрыт. Неудачный прогон
сохранён отдельно, не выдаётся за PASS.

Проверки: четыре сборки компилируются; native M09 27/27, итоговый целевой набор
M10 45/45 PASS. Кнопка открытия настроек и создание профиля проверены в Unity.
Итоговый S07 Game: текущий полный документ равен runtime карте, вода подключена,
ночные светлячки отправляются, Off/on освобождает и восстанавливает ресурсы.
Реальными кликами проверены погодные «Выкл.» и «Гроза»; Inspector подтверждает
Off/Storm. После кликов документ/черновик сохранены, source/scene hashes не
изменились, Editor preview восстановлен, scoped errors=0. Исходное время Play
возвращено в Edit Mode. Glow pixel delta при движущемся дожде не используется
как отдельное доказательство исключительно светлячкового вклада.

Локальные доказательства: Research/MapSettings_20261104/game и соседние
game-before-panel-fix/game-with-layout-error; M09/M10 XML в прежней Perf-папке.
Это проверка основных связей и кнопок, не художественная приёмка всех настроек,
GPU performance, грома с аудиоклипами или полного create/edit/save/reopen новой
карты. Новые горы, кувшинки, smoke88 и cottage experiment не добавлялись.
