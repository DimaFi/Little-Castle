## Что объединено и исправлено

- GPU instancing, автоматические лес/вода/берег/дорога/зима/снег, ручные эллипсы
  и полигоны с falloff/приоритетом/exclude/set/multiply, настройки качества и FPS.
- Мягкое свечение, независимые фазы полёта/пауз, передний план, дальний LOD.
- Предпросмотр получает read-only **текущий документ World Editor**, включая
  несохранённые реки и изменения. Runtime использует сессию MeadowSurfacePainter.
- Ячейки за границами карты не строятся; LOD сокращает подаваемые вершины,
  сохраняет равномерный seeded prefix и плавность дробной последней инстанции.
- Исправлен запрещённый в Unity 6.5 `GetInstanceID`, заменён на EntityId.
- Изменения амплитуды, размера и базового цвета инвалидируют зависимые bounds/tints.
- Диагностика CPU и аллокаций включается явно. Положительный контроль показал,
  что Mono-счётчик allocated bytes здесь возвращает 0 даже на выделение 64 KiB.
  Поэтому модуль сообщает **-1 / недоступно**, а не фиктивные 0 B/frame.
- World Editor снимает временный terrain/grass preview до сериализации при
  assembly reload. После повторного подключения исходные 18 876 grass clumps
  восстановились; исходный asset травы не регенерировался.
- По живому GUI исправлены завершение river drag после потребления MouseUp
  handle-контролом, reciprocal bounds маски травы и деревья detached preview.
  Малый реальный drag теперь завершился одной командой; точные Undo/Redo прошли.
  Escape восстановил исходную геометрию после неприемлемого большого изгиба.

## Как открыть

`Little Castle → Atmosphere → Firefly Preview (Isolated)` → создать профиль →
«Включить по всей карте». Профиль редактируется отдельно; игровые сцены и карта
не переписываются. Для явного запуска в игре есть отдельная кнопка регистрации
Resources-профиля и материала с сохранёнными настройками качества. Оба флага
авторазмещения/автозапуска в новых профилях выключены по умолчанию.

Реки B: в World Editor → Реки → «Прямое редактирование B · проверка».
Предыдущие этапы A/C, IDs и условные v10/v11 остаются действующими.

## Проверки

Все четыре C# сборки компилируются без ошибок.
Первый совместный native EditMode — **118/118 PASS**.
Дополнительный реальный GPU тест проверяет видимые пиксели instancing, непрозрачное
перекрытие, cap, границы карты, read-only поведение и освобождение mesh/material
при Off с последующим повторным подключением. Первый вариант теста не ожидал
регистрации нового blocker renderer; исправлен lifecycle тестовой сцены.
Повторный GPU прогон — **2/2 PASS**. Проверка связанной основной цепочки:
верхний/нижний конец × ширина/глубина/скорость/смещение — **8/8 PASS**,
маршрут пересчитан, одна точная Undo/Redo. Основная карта при этом не изменялась.

Финальные общие **EditMode 590/590 PASS**, **PlayMode 17/17 PASS**.
В PlayMode добавлена проверка opt-in рендерера при паузе игрового времени,
действующего cap, сохранности карты и освобождения ресурсов при disable.
Это нативные результаты данного прохода; старые 563/16 не используются как
подтверждение новой версии. Player build/целевой GPU benchmark не выполнялись.

Живой B: selection/points UI и drag проверены в основной SceneView; небольшой
сдвиг применился при release, ONE Undo/exact Redo/Undo PASS (`b-ui-status.txt`).
Неприемлемый большой сдвиг не заменил карту, Escape вернул её и preview.
Первое создание полного detached terrain заметно останавливает UI («Hold on»).
Поэтому **B остаётся WIP**, нужен региональный preview и измерение задержек,
а также ещё не пройденные spline/insertion/delete/continuation cases.

### Движение и стоимость

Записаны **330 реальных GPU кадров за 66 секунд**, по 22 секунды Low/Medium/High,
на основной карте: берег/лес/стратегическая ортографическая камера. Время сцены
и общее освещение не изменялись: использовался отдельный night preview огоньков.
Эти кадры не заменяют художественную приёмку настоящей ночи.

| Preset | CPU median после прогрева | p95 | p99 | Максимум поданных огоньков |
| --- | ---: | ---: | ---: | ---: |
| Low | 0,050 мс | 0,074 | 0,092 | 400 |
| Medium | 0,085 мс | 0,133 | 0,165 | 417 |
| High | 0,133 мс | 0,170 | 0,193 | 897 |

Замер — только CPU вызов рендерера в Editor, с исключением первых трёх секунд
каждого ракурса. Это **не GPU ms, не FPS Player и не нагрузка 50 000 огоньков**.
Холодная перестройка дала максимум **52,75 мс**: её нужно разбить на работу по
времени/выборкам перед приёмкой streaming на большой карте. В этих ракурсах
близкий слой не включился (near=0); его нельзя объявлять визуально проверенным.
GC Alloc пока недоступен через выбранный счётчик; нужен Unity Profiler/Player.

Карта и river draft до/после записи совпали; SHA исходных Surface/scene совпали.
