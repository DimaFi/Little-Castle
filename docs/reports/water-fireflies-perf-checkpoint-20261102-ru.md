## Сохранённый код

- Светлячки строят cell постепенно: до 24 шагов и кооперативного CPU-бюджета
  0,6 мс за кадр по умолчанию. Одна проба может закончиться с превышением времени.
  Лимиты доступны в `FireflyPreviewBudget`: buildSamplesPerFrame (1–256),
  buildMillisecondsPerFrame (0,05–4 мс). Несколько игровых камер делят бюджет;
  отражения читают готовые cells, не строят свои. Незавершённые cells не рисуются.
- Для Edit Mode отдельный Editor adapter продвигает счётчик один раз за update:
  офлайн render requests не обязаны менять Time.frameCount. В runtime остался
  только простой метод продвижения счётчика, без зависимости от UnityEditor.
- Предпросмотр B переиспользует terrain/water/tree presentation и их меши,
  переключая их между live и detached session. Отмена восстанавливает область
  с учётом накопленных dirty notifications и связанных маршрутов. Маска использует
  существующую preview texture. Исходные meshes/трава/каталог/LOD не изменяются.
