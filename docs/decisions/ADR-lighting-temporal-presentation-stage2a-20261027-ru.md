# ADR: согласованная публикация GI в исследовательском стенде

Дата:27.10.2026. Статус: экспериментальное решение, production adoption отсутствует.
Продолжает ADR-lighting-spatial-indirect-experiment-20261026-ru.md.

Вычисляемые пробы нельзя показывать как якобы одну версию: при плавной смене
WorldTime они имеют разный возраст. В этом эксперименте храним две полные
presentation версии и плавно меняем их за0.2s после окончания solve queue.
Solver, его детерминированность, revision gate и geometry transport остаются прежними.
Время принадлежит WorldTimeSystem; lighting только читает его снимки.

Во время geometry commit обе display histories инвалидируются в отдельных
old/new областях с поддержкой текущего решателя. Known-invalid не превращается
в открытое небо. Новая версия не принимается до окончания предыдущего fade.
Это сохраняет понятный контракт и исключает смешивание старого occlusion с новым.

Цена: дополнительный полный GPU buffer и два CPU массива, whole-field latency,
два полных uploads на publication/geometry barrier; возможна тёмная пауза после
изменения геометрии. Solve budget2ms не включает эти операции. Frustum queue
приоритет не даёт раннего видимого ответа, пока gate ждёт всё поле. Поэтому
решение не принимается как финальная схема большой карты. Region/chunk publication
рассматривать после визуального baseline с настоящим рельефом и объектами.

Приёмка изображений начинается с камеры стратегии сверху, с родными LOD и
close/mid/far zoom; interiors только диагностируют утечки. Туман/дальние тени
оцениваются отдельно. Изменения editor/authoritative state и блокировка preview
ради GI запрещены существующими границами задачи.

Проверки и реальные ограничения:
[отчёт этапа2А](../reports/lighting-gi-temporal-stage2a-20261027-ru.md).
Откат эксперимента: `-giImmediate` для прежней in-place публикации, keyword-off
для согласованного Meadow ambient baseline. Основные проекты не переключены.
