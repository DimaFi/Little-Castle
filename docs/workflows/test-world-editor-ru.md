# Как самостоятельно проверить World Editor

1. В Unity Hub добавьте существующий проект
   `E:/Games_Develop/Little-Castle_BrushFoundation_20261027`.
   Версия Unity — **6000.5.5f1**. Это отдельная рабочая копия этапа 1.
2. Откройте сцену `Assets/_Game/Scenes/Meadow_20261025.unity`.
3. Откройте меню **Little Castle → Map → World Editor**.
   База открытой Meadow-сцены подключается автоматически. Если окно открывалось
   раньше без сцены, нажмите **Подключить карту открытой сцены**.
4. Оставайтесь в **Scene**, вне Play Mode. Включите **Инструмент в SceneView**.
   Выберите инструмент, задайте радиус в метрах, силу и мягкость края.
   Кнопка **Показать всю карту в SceneView** помогает начать с общего вида.
5. Рисуйте ЛКМ; колесо — zoom, Alt/ПКМ/СКМ — навигация камеры.
   Внешний контур задаёт радиус, внутренний показывает начало мягкого края.
   Один законченный штрих соответствует одной отмене. Esc отменяет текущий штрих.
6. Для деревьев доступны карточки и паки рощ. Для реки раскройте раздел
   **Реки, песчаные спуски, броды и скалы**: точки задаются кликами, результат
   фиксируется отдельным **Применить**. Это специализированный draft-инструмент.
7. Проверьте **Отменить / Повторить** (Ctrl+Z / Ctrl+Y), затем
   **Сохранить карту JSON…** и **Открыть карту JSON…**. Для отдельного preset
   используйте **Сохранить профиль…**.

Для первого просмотра достаточно: провести дорожку, перекрыть её лугом,
поднять/опустить холм, посадить рощу, приблизиться к краю штриха и отменить его.
Повторите с большой высоты и вблизи. Сообщите выбранный инструмент, радиус,
силу/мягкость и что именно произошло — так проблему будет проще воспроизвести.

Окно работает в Edit Mode. Для проверки игрового представления используйте
Play Mode и панель Meadow. Авторский документ окна сохраняйте в JSON либо
явно применяйте к базе: обычные несохранённые правки SceneView не являются
автоматически изменением исходной сцены. Для продолжения работы после закрытия
Unity нужно сохранить/открыть авторский JSON.

Код опубликован в ветке `codex/unified-map-tools-20261027`. Локальная копия
содержит необходимые art fixtures; в чистом Git clone они требуют отдельной
синхронизации существующей библиотеки ассетов.
