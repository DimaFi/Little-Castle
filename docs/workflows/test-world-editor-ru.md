# Как проверить World Editor самому

Открывайте **E:/Games_Develop/Little-Castle** в Unity **6000.5.5f1**.
Это основной объединённый проект. Остальные рабочие копии сохранены как источники.

## Быстрый вход

1. Меню **Little Castle → World Editor → Open Integrated Scene** открывает
   `Assets/_Game/Scenes/WorldEditor_20261027.unity` и окно **World Editor**.
2. Работайте во вкладке **Scene**, вне Play Mode. Если окно закрыто:
   **Little Castle → Map → World Editor**. База карты сцены подключается автоматически.
3. Вверху окна находятся открытие/сохранение JSON, применение базы, отмена/повтор
   и **Вся карта**. Ниже — четыре раздела: **Рельеф**, **Покрытие**,
   **Растительность**, **Реки**. Настройки относятся к выбранному инструменту.
4. Для обычной кисти включите **Рисовать в SceneView**, задайте радиус в метрах,
   силу и мягкость. ЛКМ — штрих, Esc — отменить текущий штрих и выключить ввод.
   Alt / ПКМ / СКМ / колесо оставлены для камеры SceneView.

## Как создать реку

1. Выберите **Реки**, нажмите **Новая река**.
2. В SceneView поставьте ЛКМ хотя бы **две точки на земле по направлению течения**.
   Точки и линии черновика показываются до применения.
3. Нажмите **Применить реку**. Именно теперь появляются вода и вырезанный рельеф,
   а река входит в сохраняемый документ. Для первых проб используйте ровный
   свободный участок в пределах карты и ширину по умолчанию.
4. Проверьте **Отменить / Повторить**, затем сохраните JSON и откройте его обратно.
   Новые реки используют water-only профиль v2. Старые v1 читаются без конвертации.

Для изменения существующей реки используйте выбор реки и редактирование её точек.
Расширенные берега, броды и скальные участки скрыты под дополнительными настройками.
Черновик сохраняется при смене раздела. Перед сохранением документа его нужно
применить или явно сбросить; окно сообщает об этом и не теряет точки молча.

## Что попробовать

- Покрытие: дорожка, луг поверх дорожки, удаление травы. Меняйте радиус и мягкость.
- Рельеф: поднять и опустить холм, затем отменить законченный штрих.
- Растительность: цветы и мелочь, отдельное дерево, выбор/перемещение/удаление,
  затем роща из готового набора.
- Повторите близко и с большой высоты, около границ областей и на склоне.
- Сохраните **JSON**, перезапустите Unity и откройте его с той же базой карты.

**Сохранить JSON…** пишет отдельный авторский документ. **Применить к авторской
базе и маске** изменяет исходный asset карты; это нужно, чтобы результат стал
стартовой картой сцены и Play Mode. Обычный Ctrl+S сцены не заменяет сохранение
документа World Editor. Перезагрузка скриптов восстанавливает правки и черновик
реки из контрольной точки окна; история отмены после reload начинается заново.
Для надёжной передачи и резервной копии используйте JSON.

## Play Mode и освещение

Нажмите **Play**: слева используется панель **WORLD EDITOR** с теми же четырьмя
разделами. В разделе **Реки** порядок тот же: новая → точки → применить.
Панель SceneView во время Play не редактирует отдельный авторский документ.

Навигация: WASD/стрелки — движение, колесо — масштаб, ПКМ — поворот/наклон,
СКМ — перемещение, Q/E — поворот. **H** скрывает игровую панель.
В **Освещение и камера** доступны общий/близкий/стратегический вид,
**День**, **Закат**, **Ночь** и автоматическая смена суток.
Кнопка времени останавливает часы; автоматический режим возобновляет их.
Проверяйте контактные тени около диагностического куба и двух стен.

Play Mode сохраняет правки кнопкой **Сохранить** в собственный файл сессии;
они не применяются автоматически к авторскому asset SceneView. Сначала проверяйте
один режим, чтобы было понятно, какой документ открыт.

Spatial GI остаётся отдельной диагностической сценой
`SpatialIndirectStudy_20261026`, для обычного World Editor не требуется.
Динамические биомы/зима из PR79 пока не интегрированы.

Для сообщения о проблеме достаточно названия раздела/инструмента, режима
Scene или Play, радиуса/силы/мягкости и короткого описания действий.

Локальные art fixtures сохранены. Публичный Git clone требует восстановления
существующей библиотеки моделей и лицензируемых vendor assets; кодовый PR
не распространяет их автоматически.
