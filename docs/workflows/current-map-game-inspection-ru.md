# Текущая карта + вода + светлячки в Game

Это одноразовый opt-in тест в текущей открытой сцене, без замены карты примером
и без «Применить к авторской базе». Обычный Play по-прежнему использует базу сцены.

1. В World Editor закончите/отмените активный штрих. Примените нужный черновик
   реки в документ: неприменённый черновик сохраняется в окне, но в тест не входит.
2. В заголовке World Editor нажмите **Проверить текущую карту в Game…**.
3. Нажмите **Подготовить / выбрать профиль Game-теста**. Первое нажатие создаёт
   отдельные `Assets/_Game/Settings/FireflyGameInspection.asset` и `.mat`;
   последующие выбирают существующий профиль без перезаписи. Можно назначить
   другой сохранённый профиль с `materialForBuild` и включённым automaticWorld.
   Настройки плотности, среды, качества, build budget доступны в Inspector профиля.
4. Нажмите **Запустить текущую карту + светлячки в Game**. Сцена должна уже
   содержать ровно один MeadowSurfacePainter с той же базой, что и World Editor.
   Если был включён глобальный FireflyAutoWorld, предварительно выключите его
   в Firefly Preview; тест не меняет эту настройку автоматически.
5. Перейдите в Game. Используется текущий полный документ World Editor:
   неопубликованные реки, дороги, рельеф и деревья входят в начальную runtime Session.
   Существующие runtime presenters воды/рельефа/деревьев читают именно её.
   Окно теста показывает map ID, подключение воды, часы мира, Night amount,
   подключение карты светлячков, ready/pending cells и отправленные instances/draws.
6. Светлячки используют существующий NightAmount, не собственные часы. Днём они
   затушены. Можно дождаться ночи, выбрать штатную **Ночь** в игровой панели либо
   открыть из теста **Atmosphere Preview → Blue night**. Последний вариант меняет
   только presentation; **Live clock** возвращает освещение к общим часам.
   Сравнивайте воду при одинаковых времени/погоде/камере, затем осмотрите близко
   берега/деревья и опустите камеру для ближних огоньков. Дайте cells достроиться.
7. **Остановить тест / выйти из Play** возвращает обычный Edit Mode. Исходный
   asset, сцена, World Editor document и его river draft не применяются из Game.

Сохранённый профиль/материал остаются отдельными author assets. Профиль теста
не расположен по имени глобального bootstrap и имеет runtimeAutoStart=false:
создание настроек не включает эффект в shipping/обычном Play. Одноразовый
runtime renderer получает временную копию настроек, читает live Session и не
создаёт отдельный Point Light или GameObject на каждого светлячка.

Кнопка **Сохранить** игровой панели в этом тесте использует отдельный
`diagnostic-current-map-game-inspection-v6.json`, а не обычный meadow save.
Game-правки не переносятся автоматически в документ World Editor.
Тест захватывает карту перед Play, не синхронизирует изменения Edit Mode в фоне.
Для этого теста требуются обычные Domain Reload и Scene Reload в Enter Play Mode
Settings. Отключённые reload options отклоняются до Play; настройки проекта
автоматически не меняются. Границы документа должны совпадать с базой сцены,
поскольку общий mask renderer использует bounds базы.
При перезагрузке скриптов посреди Play тест освобождает собственные объекты,
разоружается и запрашивает выход из Play до потери managed references.
Изолированный diagnosticSaveId сохраняется до уничтожения игровой сцены: пока
инъецированная Session ещё жива, кнопка Save не получает обычный путь сохранения.
Обязательный Scene Reload восстанавливает исходные настройки после выхода.
Статус просит запустить тест заново. Обычный reload на входе
в Play сохраняет ещё не использованный одноразовый запрос.

Пустой кадр не означает автоматически ошибку bootstrap: дневное освещение,
Off/нулевой budget, запрет снега/зимы, неподходящий habitat, высокая камера и
незавершённые cells видимы через настройки/диагностику. Проверка загрузки не
означает художественную или performance-приёмку. Новые native результаты
фиксируются основным проходом; старые 590/17 не являются проверкой этого кода.
