# Отдельная пробная карта

Новый путь первого этапа находится в World Editor. Перед использованием нужна
проверка актуальных сборок в Unity; компиляция сама по себе не является приёмкой.

1. Открыть Little Castle → Map → World Editor вне Play.
2. Нажать «Новая карта…», выбрать папку Assets, название, ширину/длину в метрах
   и пределы высот. Для первого опыта — 128×128 м, высота 0, пределы −4…12.
3. Подтвердить сохранение текущего документа и сцен. Мастер создаёт отдельную
   папку с Map.unity, MapSource.asset, сеткой земли и собственными материалами.
   Он не копирует основную карту и её размещённые деревья/растения.
4. Работать во вкладке Scene существующими разделами World Editor. У новой
   карты ровная основа; готовый ковёр объёмной травы не создаётся автоматически.
5. «Сохранить карту в базу» сохраняет текущие правки в MapSource.asset этой карты.
   После этого сцену можно повторно открыть через «Открыть карту (сцену)…».
   «Сохранить JSON…» — отдельная переносимая/резервная копия документа. Если
   сохранён только JSON, после открытия соответствующей сцены открыть этот JSON.
   Ctrl+S сцены не заменяет сохранение документа карты.
6. «Проверить текущую карту в Game…» использует существующий одноразовый тест
   текущего документа. Светлячки подключаются выбранным сохранённым профилем
   этого теста; обычное создание сцены не включает глобальный автозапуск.
   После выхода из Play игровой тест не переносит правки обратно в авторскую
   базу автоматически. Редактирование для сохранения вести в Scene вне Play.

## Настройки систем карты

В заголовке World Editor есть «Настройки систем карты…». Там доступны:
подключение дождя к текущей камере/карте/освещению, создание сохраняемого профиля
погоды, все поля этого профиля, освещение и время суток, профиль светлячков.
Профиль погоды можно выбрать отдельно для каждой сцены. Ссылка на него хранится
в компоненте сцены: после подключения сохранить сцену Ctrl+S. Кнопка сохранения
профилей сохраняет только выбранный погодный профиль и профиль Game-светлячков.

При запуске текущей карты в Game дождь использует настроенный компонент сцены,
светлячки подключаются штатным тестом. Панель редактора слева, погоды справа.
«Выкл.», «Морось», «Дождь», «Ливень», «Гроза» и качество действуют в Play;
временные изменения компонентов после выхода из Play возвращаются к сохранённым.
Рисование не обрабатывает клики по панели погоды. Поля профиля — реальные assets,
их изменения сохраняются отдельно от временного состояния компонентов.

Размер карты задаётся при создании: текущая версия не предлагает безопасный
resize готового документа. Диапазон данных 32–512 м, решётка высот 1 м. Большие
размеры пока экспериментальные по скорости; маска покрытия остаётся 512×512.

Ровная карта не является процедурным миром. Подключение генератора и горного
обрамления — следующие этапы [плана](../plans/unified-map-authoring-20261102-ru.md).
Редактируемые горные массивы нельзя считать готовыми по наличию кисти холмов.

## Перенос в игру

MapCreationOptions/MapCreationFactory создают документ без UnityEditor. Те же
MapEditSession и команды используются кистями. MapNewDocumentWindow и
MapNewSceneFactory — Unity-адаптеры: диалоги, AssetDatabase, сцена и ассеты.
Будущий игровой интерфейс вызывает общие операции и использует своё хранилище;
зависимость от EditorWindow/AssetDatabase в runtime добавлять нельзя.
