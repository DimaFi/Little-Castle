# Little Castle · #85 · Автоматические светлячки по всему миру

Дата: 2026-11-01. Ветка: `gpt6/fireflies-auto-world-dima-20261101`. Основа: `gpt6/fireflies-visual-adaptive-preview-dima-20261101` (коммит `b95be9db9e6c7c3b9e100364d21ea3bb1ead9df3`).

## Что значит «включить везде»

**Два режима одной системы:**

- `FireflyPreviewProfile.automaticWorldPlacement = true` — режим авторазмещения без ручного рисования областей на карте. При активной `MeadowSurfacePainter.Session` читает деревья `QueryTrees` (один раз на строящуюся ячейку), `QueryWater`, `SampleRoad01`, `SampleGrass01`, `EnvironmentThemes.Sample(Winter)`, `SampleEnvironmentSnow`. Ручные зоны остаются «Exclude / Set / Multiply / Inherit» и срабатывают поверх базовой автоплотности. `automaticUseMapBounds` берёт реальные границы загруженной карты.
- `FireflyGlobalSettings.enabledEverywhere = true` — одна настройка **автоматического запуска в Play Mode** на каждой загружаемой карте. Отдельный bootstrap читает **необязательный** конфиг `Assets/_Game/Resources/Fireflies/GlobalFireflies.asset`; если его нет/он выключен, проект ведёт себя как прежде. Новый unsaved GameObject создаётся только при Play. Он переживает смену сцены, переподключается к карте и реагирует на её изменения. `profile`, `quality` и shader привязаны в отдельном config asset; shader — явная ссылка для Unity build.

**Как включить:** открыть Unity → меню `Little Castle → Atmosphere → Firefly Preview (Isolated)`, создать/выбрать `FireflyPreviewProfile`, включить «Автоматически по миру», нажать «Создать единые настройки для Play Mode», включить «Включить во всей игре». Профиль по умолчанию уже имеет `automaticWorldPlacement=true`. При открытии `GlobalFireflies.asset` можно настроить бюджет (Off/Low/Medium/High/Custom, FPS ↔ графика, adaptive FPS) и назначить shader.

При отсутствии живой `MapEditSession` авторазмещение не делает вид, будто знает расположение леса/реки; оно ждёт появления карты. Это особенно важно для меню и переключения сцен.

## Правила распределения

* Лес: расстояние до сохранённых деревьев карты с задаваемым радиусом и множителем.
* Берег/вода: рядом с действующими руслами и над водой; на воде высота берётся из `QueryWater`.
* Дорожки: вблизи данных маски дорожек, со снижением плотности на самом полотне.
* Луг: только если есть соответствующая травяная маска, с более низкой по умолчанию плотностью.
* Зима/снег: уменьшают плотность почти до нуля, множители настраиваются.
* Не допускается выход за границы карты. Используется существующая проверка `VegetationAllowed` для ограничения сухих участков, но она **не гарантирует** отсутствие огоньков внутри всех видов зданий/объектов, если построенные объекты не зарегистрированы в карте.
* Силу и радиусы источников можно регулировать в профиле. Множители выбираются через **max**, чтобы при пересечении леса/воды/дороги не возникал неконтролируемый всплеск яркости. Ограничения world cap/cell cap/LOD сохраняются. Смена данных вызывает локальную инвалидацию кэшированных ячеек.
* Время суток читает имеющийся `StylizedLightingGlobals.NightAmount`; **отдельные часы не создаются**. Реального освещения листвы/почвы нет, только видимое свечение HDR. Реакция на дождь (помимо доступного снега) и полноценное исключение всех зданий требуют будущего подключения к соответствующим данным.

## Проверить в Unity перед слиянием

1. Работать в **отдельном worktree**, не поверх локальной рабочей копии Codex с рекой B или приватными картами: `git fetch origin && git worktree add ../Little-Castle-fireflies-auto origin/gpt6/fireflies-auto-world-dima-20261101`.
2. Проверить компиляцию URP shader, C# scripts, EditMode tests `FireflyPreviewTests`. Все тесты новые/старые пока не запускались настоящим Unity Test Runner. Провести визуальную проверку каждого пресета и как минимум по 20 секунд движения.
3. Открыть основную карту, проверить лес, берег, воду, дорожки, луг, край карты и зимнюю область. Переключать `automaticIncludeForests/Water/Paths/Meadows`, проверять радиусы, множители, а также ручные Exclude и Set зоны и Undo.
4. При включённом global config запустить Play без размещения нового компонента в сцене. Проверить старт с меню, появление мира после загрузки, переход на другую карту/сцену, дневное отсутствие и плавный вечерний/ночной эффект. Проверить, что пустое меню не получило светлячков.
5. Снять real profiler CPU/GPU ms, overdraw, GC Alloc, FPS на рабочей карте, включая плотную тестовую поляну и 2 камеры (если применимо). Отдельно сравнить auto on/off, минимум 20 секунд. FPS-симуляция в Edit Mode **не** заменяет профилирование.
6. Проверить стабильность при редактировании дорог, деревьев, биомов/снега/рек — обновляются только затронутые ячейки и никакие исходные изменения не сохраняются вместе с временным эффектом.
7. Проверить build (включая явную ссылку на шейдер в `GlobalFireflies.asset`), Domain Reload off/on, Play/Stop, отсутствие дубликатов глобального объекта.

## Ограничения текущего этапа

Это **изолированное автоматическое включение и авторазмещение**, а не финальное закрытие Issue #85. Глобальная настройка — отдельный Resources asset, а **не часть сохранения карты или меню игровых настроек**. Динамическая реакция на дождь/грозу и 100% маски зданий требуют проверенного источника данных. Нет реальных Light-пятен от светлячков, не добавляются источники в NightLightBudgetManager. Базовое авторазмещение работает только там, где есть живой `MeadowSurfacePainter.Session`; если карта выводится другим runtime-рендерером, его read-only интерфейс надо подключить отдельно. При изменении конфига в Unity нужно перезапустить Play, чтобы заново сработал bootstrap.

**Не мержить в main** до реальных Unity и профайлер-тестов; не затрагивать существующие системы и изменения реки B.
