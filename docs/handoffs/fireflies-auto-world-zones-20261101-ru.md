## Задача и границы

Добавлен **общий выключатель автоматического размещения** `FireflyPreviewProfile.automaticWorld.enabled`. Включённый режим размещает светлячков по всей *активной карте* с учётом реальной геометрии деревьев, водных русел, редактируемых дорог и тематических биомов; **зоны рисовать необязательно**. Параметры базовой плотности, времени суток, свечения, качества и ручные зоны сохраняются. Приоритетные ручные области (Multiply, Set, Exclude) работают поверх автоматического расчёта.

Эта реализация независима: она **только читает** `MeadowSurfacePainter` / `MapEditSession` и существующий `StylizedLightingGlobals.NightAmount`, не меняет файлы сцен, системы рек, источники света, World Editor, проектные настройки URP и игровой save. Обе настройки (автообласти и глобальный runtime) выключены в новых профилях по умолчанию, пока пользователь сам не включит их.

## Доступные экологические сигналы и значения по умолчанию

Настройки `FireflyPreviewProfile.automaticWorld` (все доступно через Inspector профиля):

| Параметр | Значение | Назначение |
| --- | ---: | --- |
| enabled | false | Глобальный флаг автора |
| runtimeAutoStart | false | Дополнительное разрешение запуска во время игры |
| meadowWeight | 0,12 | Очень редкие фоновые огоньки на открытых лугах |
| forestWeight | 2,4 | Много огоньков у известных экземпляров деревьев |
| treeInfluenceRadius | 10 м | Радиус влияния деревьев |
| shoreWeight | 2,8 | У береговой линии / недалеко от водного русла |
| shoreSearchRadius | 5 м | Поиск воды ограниченными пробами рядом с кандидатом |
| waterSurfaceWeight | 1,3 | Над самой поверхностью воды |
| roadsideWeight | 0,95 | Редкие огоньки на обочинах |
| roadsideSearchRadius | 4 м | Расстояние от края нарисованной дороги |
| pavedRoadMultiplier | 0,04 | Почти нет светлячков прямо над самой дорожкой |
| enchantedForestMultiplier | 1,45 | Увеличение в Enchanted/Elven Forest |
| winterMultiplier | 0 | Убрать естественные огоньки в зимнем биоме |
| snowMultiplier | 0,1 | Уменьшить плотность при снежном покрове |
| maximumHabitatMultiplier | 6 | Лимит коэффициента экологии до основного графического бюджета |
| avoidReservedGround | true | Не рисовать на запрещённой для растений поверхности (кроме воды) |

**Единицы плотности остаются светлячки / 100 м²; эти числа — коэффициенты к основной плотности**, после которых применяются все глобальные лимиты и бюджеты FPS.

Карта определяется по `MapEditSession.Bounds`, **а не** по устаревшему прямоугольнику профиля. В любой точке своей карты, при подходящих условиях, система может создавать огоньки. Фактически генерируются/рисуются только видимые камеры ячейки 32 м с заданным бюджетом, а не все светлячки карты разом. При отсутствии активной `MeadowSurfacePainter`/валидной `MapEditSession` автоматический режим не создаёт ложных огоньков.

Сейчас лес определён по `MapEditSession.QueryTrees` (размещённым деревьям), берег и вода — по `QueryWater`, дорожки — по `QuerySurface` / авторским штрихам, зима, снежный покров, Enchanted/Elven — по имеющимся полям `EnvironmentThemes`, `SampleEnvironmentSnow`. **Процедурные деревья/биомы вне этой карты, погодные эффекты ливня и полноценные запреты по зданиям не интегрированы**: подключить после тестирования и анализа источников runtime. Реальную подсветку земли и деревьев эта версия не делает — это glow без real-time Light.

Сеанс карты в Edit Mode при необходимости конструируется как отдельная read-only snapshot из `MeadowSurfacePainter.source` и импортируемого рельефа/деревьев. В Play Mode используется живой `Session` только на чтение. Если snapshot невалиден, окно выдаёт сообщение вместо некорректной генерации. События карты инвалидируют только затронутые ячейки.

## Как включить (Unity)

1. Переключиться на указанную ветку **в отдельном worktree**, не в рабочей копии с незаконченными реками B:
   ```bash
   git fetch origin
   git worktree add ../Little-Castle-fireflies-auto origin/gpt6/fireflies-auto-world-zones-dima-20261101
   ```
2. В Unity открыть `Little Castle → Atmosphere → Firefly Preview (Isolated)`; открыть или создать `FireflyPreviewProfile`.
3. Включить **«Включить по всей карте»**. В SceneView (при наличии `MeadowSurfacePainter`) появится автоматическое распределение, ручные области необязательны. Настроить плотность, веса леса/воды/дорог, зимы/снега, лимиты.
4. Для необязательной глобальной активации в игре нажать **«Включить автоматически в игре»**. Окно создаст/обновит **только** `Assets/_Game/Resources/LittleCastle/FireflyAutoWorld.asset` и `FireflyAutoWorld.mat`. Сохранит выбранные пресеты качества, FPS-ограничения и ссылку на URP material/shader, чтобы избежать shader stripping. Для полного выключения в игре — кнопка **«Отключить запуск в игре»**. Присутствие профиля без `runtimeAutoStart` не включает эффект автоматически.
5. В Play Mode автоматический загрузчик проверяет наличие профиля и карты максимум раз в секунду; при появлении карты создаёт единственный `FireflyPreviewRenderer` и читает все данные экологии на лету. **Ни один существующий gameplay-скрипт или сцена не переписан.** При отсутствии `MeadowSurfacePainter` в конкретной игровой сцене он бездействует (нужна отдельная интеграция с другими картами).

## Тесты и критерии

- Unity import/compilation, шейдер URP, Editor Test Runner: `FireflyPreviewTests` теперь содержит 19 NUnit тестов, в том числе forest/water/shore/path/winter/snow/manual overrides/карта за bounds. **Они подготовлены, но не запускались в Unity с этой стороны**.
- Проверить SceneView: лес, берег и вода, дорожка/обочина, открытый луг, зимняя зона и снежный участок; минимум 20 с на выбранный пресет; ночь/день/сумерки. Убедиться, что локальные Exclude/Set/Multi остались рабочими.
- Проверить большой мир и активные редактирования в World Editor: локальная перестройка кэша, отсутствие резких вспышек/скачков, стабильный seed.
- Для реальных FPS и GC Alloc провести профилирование **Play Mode / Game camera** на целевом железе с включением и без светлячков. UI симуляции FPS не является замером. Проверить Low/Medium/High, ортографический/перспективный вид, отражения и 1 000/10 000/50 000 *потенциальных* огоньков, реальные ограниченные лимитами.
- Отдельно убедиться, что runtime Resources-активация не создает объекты при выключенной опции, не вмешивается в реки B, освещение, снег и сохранения карт.
