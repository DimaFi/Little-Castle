Дата: 2026-11-04. Основа: интеграционный checkpoint PR #95 @ 4c241aa; задача #94.

## Состояние
Экспериментальная **отдельная ветка**, stacked на `codex/integrated-project-checkpoint-20261104`.
Это source-level кандидат для Unity QA, а **не визуально принятая сборка**.
Автоматически в main / PR #95 не сливать; авторскую карту, сцену, дым PR #88,

Публичный checkpoint всё ещё не содержит 32 ссылки на локальные tree/rock GUID и актуальную пользовательскую карту.

## Что изменено
1. `MapWeatherBiomeMask`: одна 48×48 RGBA32 маска на область 176×176 м вокруг
   главного World Editor / Game focus; одинаковая winter-смесь по world XZ для дождя
   и снега. Вес = плавная функция max(Winter-theme, видимого snow coverage).
   Bilinear сглаживает границу биомов. Повторное заполнение ограничено ~0.65 с,
   мгновенное обновление при перемещении фокуса более 12 м.
2. `LC_RainStreak`, `LC_WeatherWet`, `RainStormController`: тёплая доля
   пропускает жидкий дождь; снежная доля подавляет жидкие частицы, мокрый
   блеск, часть локальных рябей и капли с карнизов. Нет raycast на каждую каплю;
   прежние настройки укрытий и существующая логика накопления влажности сохранены.
3. `MapSnowfallPresentation` + `LC_Snowfall.shader`: снег больше не гасится
   глобальным rain intensity. В зимней части карты плотность снежинок растёт при
   Мороси → Дожде → Ливне → Грозе. Одна фиксированная сетка 512 billboards,
   без спавна отдельных GameObjects. Лёгкий снег по умолчанию 0.17; у
   `MeadowSurfacePainter` появился Inspector `ambientWinterSnowfall` (0–1,
   0 полностью отключает фоновые снежинки при погоде Off).
4. Более заметные локальные круги дождя (`LC_RainRipple`) и ограниченное
   увеличение числа pooled surface splash particles в ливень; без новых
   рендера реки, материалов водопада или физики для каждой капли.
5. `DayNightLightingController.Atmosphere` использует существующий день/ночь
   и профиль, но отдельно усиливает тёмную облачность, затемняет ambient/direct,
   слегка холодит цвет и fog во время Storm. Есть fallback для сцен без
   полного `AtmosphereProfile`, работающий на существующем runtime sky clone,
   без изменения авторского skybox-материала.
6. Дальние молнии: новый **оригинальный** URP HDR additive shader
   `LC_StormLightning`, main+branch и мягкий glow. Детерминированный seed,
   молния в верхней видимой части камеры, без ударов в персонажа/объекты/землю.
   Двойное/тройное мерцание ~0.4 с, краткая подсветка skybox,
   опциональный thunder sound с задержкой. Первый удар в режиме грозы
   планируется примерно через 5 с после достижения порога; далее 10–24 с
   по профилю `MapWeather.asset`. Кнопка Game debug **«Показать молнию сейчас»**.
   High/Custom: core+glow; Low/Medium: только core/branch. `reducedFlashes`
   снижает мерцание. Материалы и глобальные значения очищаются на Disable.
7. Изучена готовая MIT-система `sonereraslan/unity-lightning-system` (Unity 6,
   URP17). Не импортировалась: собственный модуль здесь существенно меньше
   и не требует посторонних компонентов/сцен/внешнего Bloom-пакета.
   Можно отдельно сравнить художественный результат в Unity.

## Изменения API / настройки
- `MapSnowfallPresentation.EvaluateIntensity(..., ambientSnow=0.17)`:
  последний параметр необязательный, прежние вызовы совместимы.
- `MeadowSurfacePainter.ambientWinterSnowfall`: настройка Inspector.
- `DayNightLightingController.SetStormPresentation(float)`: задаёт
  атмосферу только для существующего weather presenter.
- Shader globals: `_LC_WeatherBiomeMap`, `_LC_WeatherBiomeBounds`,
  `_LC_WeatherBiomeEnabled` и `_LC_StormFlash`; по умолчанию нейтральны
  и очищаются владельцем.

## Риски и честный статус
- **Не выполнялся Unity PlayMode, сборка Player, GPU/shader-compile и
  визуальная приёмка в этом чате.** Были только GitHub code reading,
  простые статические проверки и добавлены (но не запущены) Editor tests.
- Global mask относится к одному gameplay-camera focus и ограничена 176 м;
  производственный multi-camera/зоны/MP transport требуют отдельной задачи.
- Оригинальный lightning glow ожидает HDR/Bloom для художественного свечения;
  без Bloom видимая core-линия всё равно есть, но стиль может потребовать
  настройки. Молнии не взаимодействуют физически с картой.
- Объектов, арта и локальных карт на ветке не заменяли; нет автоматического
  merge в существующие PR.
