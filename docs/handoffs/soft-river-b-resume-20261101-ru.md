## Что уже есть в B

- `MapRiverSpline`, сохранённые ручки по node ID, параметр сглаживания и
  ограниченные производные поправки. Старые points используют прежний Catmull–Rom.
- `MapRiverNodeEditing`: точная вставка через de Casteljau, интерполяция
  параметров, стабильный новый ID и защита последних двух узлов.
- `MapRiverPicking`: пересечение луча с самой водной лентой, включая уклон.
- `MapEditSession.ApplyRiverEdit`: валидация полного кандидата и пересчёт
  зависимого маршрута перед одной командой истории. Карта не меняется при отказе.
- `MapRiverEditSolver`: максимум 12 фиксированных попыток; сглаживание,
  внутренние узлы на изгибе — сужение до 15%, переход до 50%, обход до 1 м.
- `MapRiverEditGesture`: отдельный preview, последний корректный результат,
  одна команда на release, Escape без компенсирующего Undo, защита от смены
  карты/прав во время жеста. Detached preview не накапливает историю.
- Editor: выбор по воде, узлы/направление/коридор, position/width/depth handles,
  ручки сплайна, точные параметры и scope точка/река, shift-вставка,
  вставка/удаление кнопками, продолжение свободного конца. Ручки связаны по умолчанию.
- Preview земли/воды/маски растительности отделён от live session; solver
  ограничен частотой 5 Гц. Живые renderer/terrain сохраняют detached session
  между выборками, изменяются по локальным уведомлениям.

### Сохранение

Обычные карты по-прежнему экспортируют v10. Карты с активной формой/ручками — v11.
`MapRiverLegacyV10` замораживает старый fingerprint, v2–9 также не расширяются.
Старый save не может стереть активные ручки; v11 загружается атомарно.
Новый профиль не применяется к source asset автоматически.
