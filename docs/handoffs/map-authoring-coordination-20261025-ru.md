## Этап 2: ограниченный рельеф, 26.10.2026

Реализованы поднятие/опускание земли в общей MapEditSession, с плавным краем,
радиусом и силой. Нижняя/верхняя границы — параметры авторской карты. Пробные
пределы Meadow: -4…12 м, не утверждённые ограничения производственных карт.
В SceneView есть настройка пределов документа; диапазон должен вмещать все
существующие значения. Это изменение базы с новой историей, после него отдельно
сохранить JSON или применить авторскую базу. Игровая панель показывает пределы,
не открывает игроку их изменение. MapEditAccess.Terrain проверяется общей сессией.

### Данные и реализация

- `MapHeightField.cs`: plain-data мировая решётка, разреженные базовые блоки
  16×16 samples, итоговые изменения узлов, protectedAreas. Один пограничный узел
  общий для соседних views. Высота интерполируется по диагонали реального меша,
  нормали используют соседние мировые выборки.
- `MapEditSession.Heights.cs`: BeginHeightStroke / AppendHeightPoint / Commit,
  единая история с покрытием, Cancel, Clear, Undo/Redo и проверка доступа.
  При отзыве прав активный preview откатывается. Высоты ограничены параметрами
  базы. Защищённые Rect с отступом одного шага предотвращают изменение соседних
  треугольников внутри защищённой области.
- `MapEditSave` теперь **v3**, сохраняет конечные изменённые узлы. v1/v2 покрытия
  мигрируют; v2 fingerprint проверяется по точной старой схеме без высот.
  Файл `meadow-map-edits-v3.json`; старые v2/v1 остаются нетронутыми и служат
  последовательными fallback для загрузки. MapAuthoringDocument/WorldSaveState
  остаются общими, второй формат мира не введён.
- `SurfacePaintData.hasHeightBase` отличает явно сохранённую базу от пустого
  экземпляра нового serializable class, который Unity создаёт в старом ассете.
  `MeadowSurfacePainter.CreateDocument` импортирует существующую землю, если
  marker отсутствует. Прежний Meadow не становится плоским при миграции.
- `MapTerrainPresentation.cs`: временные mesh views по16×16 исходных ячеек,
  локальная перестройка vertices/normals/bounds. Для прежней подложки200×200 м
  это144 небольших views вместо одного меша; это ограниченный Meadow-адаптер,
  а не материализация большой игровой карты. Решётка view проверяется на
  совпадение с авторитетной решёткой до изменений представления.
- Коллизия использует **отдельные меши**, очередь без дубликатов и не более
  двух recook за кадр. Кисть выбирает только свою землю через один nonalloc
  physics query, не через попадание в дерево/тестовый объект. При переполнении
  фиксированного массива попаданий используется корректный fallback.
- Native grass сохраняет прежние LOD meshes/UV/материалы. Изменяются только
  матрицы и bounds затронутых patches во временной копии данных. Базовые высоты
  и нормали опор кешируются. Внутри patch растения вне dirty bounds не
  пересчитываются. Повторная финальная нотификация того же мазка не вызывает
  ещё одну перестройку: используется transient HeightRevision.
- Акценты/декор читают ту же поверхность; scatter перестраивает локальные
  области. Существующие наземные LODGroup (Oak и предметы) служат временными
  опорами с сохранением исходного offset и вертикали. Дорожки остаются маской
  на деформируемой земле. Тестовый движущийся объект читает актуальную высоту.
- Editor preview восстанавливает renderer/collider state, matrices и tree
  transforms перед сохранением сцены, при закрытии окна и перед Play Mode.
  Save guard подключает preview заново после сохранения. Источники мешей,
  сцена, материалы и свет этим проходом не перезаписаны.

### Ограничения и передача свету

Полного стримера ручной карты, navigation/NavMesh, сглаживания/выравнивания и
вертикальных уступов ещё нет. Навигация может подписаться на MapRegionChange.Height
с локальными bounds и preview=false. Массовые trees/object records относятся
к этапу3; текущие anchors не заменяют их авторитетные ID и каталоги.

Опора травы следует поверхности на уровне пучка и его касательной плоскости.
При очень резкой кривизне отдельные корни внутри пучка могут расходиться с
землёй. Для точного per-blade прилипания понадобится height sampling в общем
grass shader и согласованные visible/depth/shadow/normals passes. **Это запрос
для будущей интеграции, не реализованное изменение шейдеров**. Общие шейдеры,
глобальные параметры света и URP-профили по-прежнему не менять в этом чате.

Следующий согласованный этап — галерея и кисть Oak A/B/C/D с настоящими превью,
стабильными итоговыми instance records, расширяемыми каталогами и правами
разработчика/игрока. Реки — после него, как в каноническом плане.

### Данные и доступ

- MapTreeInstance хранит конечные ID, archetype/version, позицию X/Z, yaw,
  scale, groundOffset, clearance и playerEditable. Высота берётся из общей
  поверхности. Адаптер ToWorldSpawn использует существующий WorldSpawnData.
- Save v4: treeOverrides и removedTreeIds относительно базы; Clear возвращает
  исходные деревья. V2/V3 мигрируют с прежним fingerprint, сохраняя импортированную
