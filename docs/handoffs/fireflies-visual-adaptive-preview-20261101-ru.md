## Что изменилось

1. **Полет:** независимые фазы паузы для каждого светлячка, плавный вход/выход из остановки, несинхронное мерцание. Настройки в `FireflyPreviewProfile`: `motionPauseFraction` (0…0,8; 0,22 по умолчанию), `motionCycleSeconds` (2…25 c; 7 c), уже имевшиеся скорость/амплитуда/ветер.
2. **Свечение:** отдельная ширина яркого ядра `brightCoreRadius` (0,05…0,32; 0,13), сила мягкого ореола `haloStrength` (0…0,5; 0,2), ограничение размера в пикселях `maxDiameterPixels` (3…20; 11). Параметры рассчитываются в индивидуальном URP-шейдере, без дополнительных real-time Lights.
3. **Дальний LOD:** `farLodStartFraction` (0,25…0,95; 0,58 дальности), `farLodSurvivalFraction` (0,05…1; 0,28), `farBrightnessFraction` (0,1…1; 0,65). Дальние огоньки постепенно прореживаются стабильным per-point seed с мягким переходом, уменьшают размер и яркость; случайность не перекидывается при анимации. **Ограничение:** это преимущественно shader/fragment LOD; CPU submission и vertex workload сами по себе не уменьшаются пропорционально. Сравнить GPU cost в профайлере на целевом устройстве.
4. **Адаптивный бюджет FPS:** поля `FireflyPreviewBudget.adaptiveEnabled` (по умолчанию true), `targetFps` (20…144; 60), `minimumAdaptiveScale` (0,2…1; 0,35). При снижении общего FPS в *Play Mode* только этот предпросмотр постепенно уменьшает число мировых/близких огоньков и дальность. Измерение — сглаженная `Time.unscaledDeltaTime` Game камеры, не GPU-время эффекта; шаг проверки 0,8 с, гистерезис, медленное восстановление. **Обратите внимание:** если падение FPS вызвано не светлячками, контроллер тоже уменьшит их бюджет — это защитный механизм, не автоматический GPU-профайлер.
5. **Окно предпросмотра:** `Little Castle → Atmosphere → Firefly Preview (Isolated)`; управление автобюджетом, FPS и минимальным масштабом, диагностический текущий множитель. **Только в Edit Mode** можно включить симуляцию низкого FPS — значение не является результатом измерения сцены. В окне появились кнопки `Тест: очень плотная поляна` (80 огоньков / 100 м²) и `Пример: 3 скопления`. Создаются только области в отдельном `FireflyPreviewProfile` с Undo, не объекты мира/карты.
6. **Устойчивость к правкам:** расширен сигнатурный контроль профиля, чтобы редактура областей через Inspector перестраивала только кэш предпросмотра.

## Что проверить в Unity (ОБЯЗАТЕЛЬНО)

1. Открыть project в его установленной Unity/URP версии, импортировать ветку; исправить ошибки компиляции, если выявятся. Затем Test Runner → EditMode → `FireflyPreviewTests`. **Тесты в Unity ещё не запускались с этой стороны.**
2. Открыть основную карту и меню предпросмотра, создать отдельный asset профиля; выставить `mapBounds` по карте. В SceneView проверить день/ночь и три природных скопления. Провести минимум 20 секунд непрерывного наблюдения каждого пресета.
3. Кнопка тестовой поляны, затем Low/Medium/High/Custom и ползунок графика↔FPS. Сравнить желаемые и отправленные количества, draw calls, missing cells, ограничения бюджета. Проверить что за краями карты ничего нет, что вблизи/вдали нет крупного Bloom и рывков движения.
4. Включить *симуляцию* 20–30 FPS и убедиться, что `AdaptiveScale` постепенно уходит к нижней границе; выключить симуляцию — в EditMode масштаб должен возвращаться к 1. Это **логический тест**, не замер производительности.
5. Для настоящей проверки контроллера при Play нужна ручная тестовая сцена или временно добавленный тестовый объект `FireflyPreviewRenderer` с тем же asset-профилем и привязанной камерой, **не сохраняемый в канонических игровых сценах**. Окно предпросмотра при входе в Play уничтожает свой временный объект специально, поэтому не проверяйте через него runtime FPS. Сравнить FPS baseline, GPU/CPU frame time, overdraw и GC Alloc 0 B/frame после прогрева (цель, не подтверждённый результат).
6. Проверить ортографическую и перспективную камеры, повороты/телепорты, низкий/высокий вид, туман, HDR/Bloom, непрозрачные поверхности, reflection cameras, профили времени суток. Не объявлять реальное освещение леса: текущий эффект рисует свечение, но **не освещает землю/деревья**.
7. Убедиться, что world editor, река B, сохранения карт, Day/Night, материалы и основные сцены не изменены. Отдельно проверить рендер без URP depth texture при выключенном soft depth fade.
