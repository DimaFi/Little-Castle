# Little Castle — тихий зимний снегопад (2026-11-02)

## Проблема на основной карте — 04.11.2026

Пользователь видит дождь над снежным участком и не видит снежинок. Конкретная
задача с ожидаемым локальным переходом и проверками: GitHub issue #94,
https://github.com/DimaFi/Little-Castle/issues/94.

Система PR92 уже перенесена локально в cc0853c, но этот коммит ещё не опубликован
в общей ветке. Проверка исходников выявила: глобальный `_LC_WeatherRainIntensity`
полностью подавляет снег при значении от 0,5. Глобальный дождь при этом не
переключается локально на снег по биому. Это объясняет наблюдаемый конфликт при
сильном дожде; наличие материала и фактические значения биома ещё надо проверить
в Game. Исправление и визуальную приёмку не считать выполненными.

База: `codex/water-fireflies-integration-20261102`, `14420d9d98d47fa15a779212113e9a56a12678f8`. Отдельно от дождевого PR #91 и дыма PR #88.

## Что меняется
- До этого `MapSnowfallPresentation.Tick` показывал снежинки только если `EnvironmentSettings.simulateWeather=true` и `snowfallIntensity>0`.
- Теперь зимний биом (`Winter` theme) или покрытая снегом территория (`SampleEnvironmentSnow`) получают мягкий базовый снегопад интенсивности 0.17 при полной силе зимнего поля, даже когда имитация погоды выключена.
- Дополнительно заданный ранее `snowfallIntensity` продолжает работать, более сильная погода имеет приоритет.
- При интеграции с дождевым PR #91 читаем `_LC_WeatherRainIntensity`; дождь подавляет одновременные снежинки. Если дождь не установлен, глобальное значение по умолчанию 0 — старый летний мир не меняется.
- Без новых камер, новых Particle Systems, моделей, другой карты или собственной погодной системы. Используется существующий шейдер/сетка и `_LC_Wind`.

## Как проверить в Unity
1. Переключиться в чистый worktree ветки, не стирать изменения пользователя.
2. Запустить нынешнюю карту в Game через существующий `MeadowSurfacePainter` и найти участок с зимним биомом или сохранённым снежным покрытием.
3. Даже с выключенной `simulateWeather` должны появляться **редкие лёгкие снежинки** в ограниченном радиусе вокруг фокуса камеры.
4. Проверить переход в летний участок — снег не должен идти. Проверить сильный снег через прежнее `snowfallIntensity`, что он остался функциональным.
5. После интеграции PR #91 проверить одновременно включённый Rain/Storm — снежинки уменьшаются или пропадают.
6. Сравнить близкий/дальний zoom, ночь/день, движение камеры, сохранённую карту.
7. Run EditMode `AmbientSnowfallTests`. Unity/Play/GPU здесь не запускались; результаты не заявляются.

**Ограничения:** нет новой системы метелей, биомного накопления осадков, физического взаимодействия с крышей или SceneView-предпросмотра. Проверка фактического состояния текущей пользовательской сцены — обязательна. Не объединять автоматически.
