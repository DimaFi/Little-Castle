# Rain Shelter — мягкие укрытия на префабах зданий

Связанные материалы: [основной дождь PR #91](https://github.com/DimaFi/Little-Castle/pull/91), задача #89.
Версия для Unity 6000.5.5f1 / URP 17.5.0. Изолированно добавлено в дождевую feature-ветку.
**UNITY НЕ ЗАПУСКАЛСЯ: визуальная корректность и компиляция требуют локального теста в Game.**

## Что решает
Авторская настройка **ОДНОГО ПРЕФАБА**, а не каждого экземпляра дома на карте:
- площадь крыши, защищающая от дождя, может быть прямоугольной и повёрнутой вслед за зданием;
- параметр `edgeFade` задаёт плавное снижение числа видимых капель и степени намокания у края;
- `irregularity` слегка разбивает идеально прямую границу, сохраняя непрерывность;
- крыша сверху продолжает мокнуть: по высоте защита плавно появляется **только ниже** отметки маркера;
- `protection` управляет остаточным дождём под навесом: 1 = полностью сухая середина, 0.7 = остаётся 30% дождя;
- несколько областей на одном сложном префабе допустимы (крылья, навесы, дворики);
- отдельные `RainRoofDripSource` на карнизах (также на префабе) управляют редкими стекающими каплями через общий пул.

## Быстрая настройка уже существующих зданий

1. Получи ветку `feature/rainstorm-cozy-weather-preview-20261102` в чистый worktree. Не заменяй текущую карту, не затрагивай smoke PR #88.
2. В окне **Project** выдели один или несколько **Prefab assets** зданий (`.prefab`). Можно выделить уже размещённый prefab instance, инструмент найдёт asset-источник. Никакого изменения экземпляра сцены не требуется.
3. Меню: `Little Castle > Weather > Configure Roof Shelter on Selected Prefabs`. Скрипт вычислит приблизительную высоту карниза и XZ-габариты геометрии, добавит дочерний `Rain Shelter` с `RainShelterVolume`, сохранит изменения прямо в каждый выбранный **prefab asset**.
4. Открой префаб в **Prefab Mode** и выдели дочерний `Rain Shelter`. **Синяя рамка** — внешняя граница, **зелёная рамка** — приблизительный сухой центр. Подвинь маркер на нижнюю сторону карниза с помощью стандартного Position Handle; измени размеры двумя редакторскими Handles или числами `Half Width / Half Depth`. Для сложной архитектуры создай дополнительные дочерние `Rain Shelter` вручную.
5. Если нужны капли, стекающие с крыши, меню `Little Castle > Weather > Configure Roof Drips on Selected Prefabs`. Две точки-карниза A/B добавятся **в исходный префаб**. Это лишь предложение позиции — подправь в Prefab Mode. Для множества скатов поставь больше источников вручную.
6. Для теста в текущей Game-сцене: `Little Castle > Weather > Create Cozy Rain Preview in Current Scene`, Play. Режимы Off / Drizzle / Rain / Downpour / Storm и Low / Medium / High. Перемещай камеру вокруг того же дома и зайди под карниз: полосы дождя должны мягко исчезать, лужи и влажность под навесом ослабевать. Над крышей дождь остаётся.
7. Любое изменение префаба отразится в **существующих и новых экземплярах**, если у экземпляров нет конфликтующих prefab overrides. Не нужно расставлять отдельные маркеры для каждого дома.
8. `.fbx` — **не редактируемый Prefab asset**. Создай обычный wrapper-prefab или prefab variant над моделью и назначь объектам сцены этот префаб; не пытайся записывать RainShelterVolume внутрь импортированного FBX. Инструмент намеренно работает только с `.prefab` и не заменяет объекты на карте автоматически.

**Важно:** если префаб содержит очень высокую башню, надстройки и разные скаты, общая прямоугольная оценка размеров/высоты может быть неверной. Открой Prefab Mode и передвинь/раздели области на реальные части крыши.

## Как получается мягкий край и почему это дёшево

- `RainShelterVolume` — компонент только с геометрическим описанием, без ParticleSystem/PhysicsCollider/Material/WeatherManager. `OnEnable/OnDisable` регистрирует готовые экземпляры в общем списке.
- `RainShelterMask` формирует **одну** временную маску 256×256 для камеры на участке 152×152 м. В R хранится плавная защита от дождя, в G — высота крыши. Размер и число сэмплов НЕ зависят от числа домов в мире. Обновляется каждые ~0.75 сек или при существенном движении камеры, проходит только прямоугольники ближайших маркеров, без физической проверки каждой капли.
- `LC_WeatherWet.hlsl` читает маску по мировым XZ-координатам. `LCWeatherShelterCoverage(worldPos)` использует мягкий горизонтальный и вертикальный фейд, защищая поверхность **под крышей, но не саму кровлю**.
- Существующие `LC_Terrain.shader`, `LC_StylizedLit.shader`, `LC_FoliageURP.hlsl` используют маску как множитель погодной влажности. Нулевая интенсивность дождя оставляет старое освещение/снег неизменным.
- `LC_RainStreak.shader` умножает альфу капель на `1 - shelterCoverage`. Больше не требуется полностью выключать весь дождь вокруг камеры в момент входа в крытую зону — другие капли за карнизом сохраняются.
- `RainStormController` уменьшает прозрачные лужи и пульсацию брызг под крышей по тому же полю `RainShelterVolume.CoverageAt`.
- Укрытие не мешает прошлым маскам воды/биомов, не изменяет saved map, не добавляет доп. свет/солнце/камеру и не создаёт отдельный материал или рендерер на дом.

## Рекомендуемая художественная настройка

Для маленького домика:
- `Half Width` / `Half Depth` — реальные размеры свеса крыши, учитывая scale;
- `Edge Fade` = 1.0–2.2 м — дождь постепенно заходит под карниз;
- `Protection` = 0.95–1.0 — сухая зона под крышей;
- `Irregularity` = 0.1–0.2 — нет визуально ровного «обреза» дождя;
- `Vertical Fade` = 0.5–1.0 м — крыша продолжает мокнуть, под нею суше.

Для навеса `Protection=0.65–0.85`, `Edge Fade=1.5–3.0`; ветер может заносить отдельные капли. Не делай абсолютно нулевой дождь непосредственно за краем.

## Проверки и ограничения

- [ ] **Unity import/compile:** проверить новый C#, Editor Handles, шейдерный include, GLES/DX12/Vulkan по target platform; Unity/GPU в GitHub-среде не запускались.
- [ ] **Prefab coverage:** настрой 2–3 типовых дома, применяй сохранённые настройки и проверь 5+ экземпляров с разными вращениями и масштабами без ручных scene overrides.
- [ ] **Soft boundary:** медленно прокати камеру через карниз, низкий и высокий ракурс, проверяй границу без мерцания. Проверь крышу сверху и мокрую стену снаружи.
- [ ] **Multiple roofs:** площадь 152×152 м, несколько соседних домов, пересечение двух масок, большие навесы, мокрая площадь рядом.
- [ ] **Near/Far camera:** camera pan/teleport, обновление маски во время движения, кэш без десятков полных Physics raycasts.
- [ ] **Perf:** время перерисовки маски, upload GPU, shader fetch cost и VRAM, сравнить Off/Low/Medium/High.
- [ ] **Cleanup:** после Disable/Destroy/SceneUnload маска отключается и временная текстура освобождается.
- [ ] **Regression:** River/waterfalls, snow, fireflies, clouds, night lighting, authored map, user meshes, PR #88 smoke.
- [ ] **Visual QA:** размер отверстия в дожде должен соответствовать карнизам; не заставлять дождь пропадать в воздухе выше крыши.
- [ ] Ограничение: footprint описывается XZ-площадью. Не решает автоматически сложную многоярусную крышу, арку, навес с отверстиями, полупрозрачную кровлю; для них используй несколько маркеров.
- [ ] Ограничение: высота крыши хранится в маске с шагом примерно 0.6 м, интерполируется и может потребовать более тонкой настройки для маленьких низких навесов. Высота хранится относительно камеры ±40/120 м и клипуется вне этой области.
- [ ] Ограничение: при очень быстром движении и больших динамических зданиях возможно запаздывание маски до следующего обновления (~0.75 сек); при желании инвалидация через events.

**Никаких автоматических изменений приватной карты, сцен или prefab assets в GitHub.** Затрагиваются только код и инструменты. Автоматическую настройку пользователь запускает сам на выбранных префабах в Unity.

## Для Codex

Сначала безопасно запустить в Unity на 2–3 домах, исправить возможную компиляцию/API и проверить Game. Обязательно адаптировать верхние скаты и навесы по реальной геометрии. Только после профилирования и просмотра перехода одобрять автоматическую настройку всего каталога зданий и мерж. Исходный код здесь — рабочий кандидат с непроверенными Unity эффектами, **а не гарантированная production-система**.
