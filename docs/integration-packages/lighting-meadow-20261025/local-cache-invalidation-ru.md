# Локальная инвалидация будущего непрямого света

Это граница последующей интеграции, не реализованный пространственный GI.
Текущий совместный baseline использует hemisphere ambient, солнце/луну и SSAO.
Редактор карты не зависит от готовности светового кеша.

Обновление 26.10: в рабочей копии карты уже существует
`MapEditSession.Changed(MapRegionChange)` в `World/Runtime/MapEditSession.cs`.
Его bounds — Rect мировых X/Z, kind сейчас Surface|Decoration, preview — флаг
живого мазка. Световой адаптер должен игнорировать дорогой пересчёт при
preview=true, а после preview=false инвалидировать только эти bounds с halo.
Не добавлять параллельную систему команд. Height/Occluder/Reflectance ниже —
предлагаемые будущие причины инвалидации, а не уже имеющиеся enum редактора.
У текущего события нет transaction revision: до отдельного согласованного
расширения адаптер света может владеть своим монотонным presentation epoch.
Не использовать authored.revision как счётчик каждого мазка: это версия базы.

## Вход от редактора

После завершения транзакции (commit / undo / redo / load delta) передавать
идентификатор транзакции и ревизию, старые и новые world-space AABB, тип правки:
Height, Occluder, Reflectance, LocalEmitter. Не отправлять отдельную транзакцию
на каждое промежуточное движение кисти. Высоты и упрощённые препятствия читать
из согласованного снимка данных карты. Unity Renderer не является save-state.

Перемещённый объект инвалидирует старую и новую области отдельно. Не брать
один огромный AABB между далёкими положениями. При сносе нужны прежние границы.
Изменение цвета дорожки затрагивает отражённый вклад; изменение высот/стен/крыш —
также видимость неба. Каждую травинку и лист не включать в препятствия GI.

## Производный кеш

Предлагаемый первый эксперимент: ограниченная сетка проб вокруг видимой области,
упрощённая геометрия, отдельные видимость неба и одно отражение. Размер ячейки,
радиус переноса, вертикальные слои и бюджет выбираются по будущему измерению.
Нельзя обещать фиксированную цену до реализации и проверки тонких стен.

Границы правки расширять на конечный радиус влияния решателя; проецировать на
затронутые тайлы в мировых координатах, в том числе отрицательных. Объединять
повторные тайлы в очереди, сохранять последний revision и объединённые причины.
Для каждой порции работы передавать immutable input snapshot. Публиковать
результат только если revision всё ещё актуален; устаревшее завершение отбрасывать.

Потребитель обрабатывает ограниченное число проб / uploads и ограниченное время
за кадр. Сначала видимые dirty tiles; соседние — позже. Не блокировать мазок,
undo или первый кадр ожиданием GI. При отсутствии/просрочке кеша использовать
управляемый общий ambient. Переход к новым данным интерполировать, сохраняя
старые валидные значения до готовности соседей. Пересчёт всей карты на мазок
запрещён. Разгруженный тайл освобождает только производные GPU/CPU-ресурсы.

Изменение солнца не равно изменению геометрии: кеш sky visibility / препятствий
сохранять, lighting injection обновлять отдельно по бюджету. В будущем отдельно
проверить безопасное поведение на границах fog of war, чтобы свет не выдавал
скрытые игровые объекты.

## Приёмка следующего прототипа

Крыша уменьшает свет неба; освещённая земля даёт цветовой вклад стене, в том числе
от объектов вне кадра. Снос/строительство/undo обновляют только затронутые тайлы.
Поворот камеры не выключает вклад. Сохраняются контроль утечек через тонкие стены,
fallback вне области, отсутствие двойного ambient и воспроизводимый revision gate.
Измерять CPU правки, очередь, проб/кадр, uploads, latency до сходимости и GPU
отдельно от SSAO. Затем выбрать решение и записать ADR. Эти проверки ещё не выполнены.
